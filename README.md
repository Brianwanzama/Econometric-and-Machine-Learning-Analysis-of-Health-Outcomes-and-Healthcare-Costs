## Disclaimer
- The dataset used in this analysis is **entirely synthetic**.  
- All statistical results and machine learning performance metrics are **not factually correct** and do **not** represent real-world clinical or financial data.  
- This project is intended solely for methodological demonstration and model development practice.
---
## Objective
- The primary objective of this study is to develop and evaluate statistical and machine learning models capable of explaining and predicting individual-level outcome measures using synthetic data. The analysis emphasizes model interpretability, predictive performance, and proper evaluation techniques.
---
## Features Considered
The synthetic dataset includes the following features:
- **Age:** Age of individuals (in years)  
- **Gender:** Binary indicator of sex (e.g., 1 = male, 0 = female)  
- **Insurance Status:** Indicator of insurance coverage or provider category  
- **Medical Condition:** Categorical indicator of underlying condition or diagnosis  
- **Admission Type:** Type of admission (e.g., emergency, urgent, elective)  
- **Billing Amount:** Total monetary charges associated with an individual record
